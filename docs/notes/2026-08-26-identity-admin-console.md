# لوحة إدارة الهوية — تشغيل تقني

صفحة [`/admin`](https://id.bhd-om.com/admin) لأدمن المنصة فقط (`BHD_PLATFORM_ADMIN_EMAILS`).

## القدرات

- قائمة مستخدمين مع بحث، تاريخ انضمام، آخر دخول، IP، وعدد التطبيقات المرتبطة.
- لوحة تفاصيل: بيانات الحساب، عنوان SELF، ارتباطات SSO لكل `client_id` (أول/آخر نشاط).
- إجراءات: تفعيل/إيقاف، توثيق بريد يدوياً، إعادة إرسال رابط التفعيل، إرسال رابط إعادة كلمة المرور.
- تبويبات: المستخدمون / النظام / عملاء OAuth.

## ملاحظات

- «الاشتراكات» هنا = ارتباطات SSO الفعلية من `bhd_oauth_tickets`. خطط الفوترة تبقى في قواعد المنتجات على `bhd_sub`.
- IP يُسجَّل عند التسجيل، الدخول، SSO authorize (`last_login_ip` / `signup_ip`).
- إعادة الإرسال تتطلب `RESEND_API_KEY` + نطاق مرسل موثّق في Resend.
