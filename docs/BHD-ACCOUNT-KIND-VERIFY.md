# توثيق نوع الحساب — شخصي أو تجاري

تاريخ: 2026-11-01  
الصفحة: `https://id.bhd-om.com/account`

## السلوك

- على صفحة الحساب يختار المستخدم **شخصي** أو **تجاري** (نفس تبويبات نوع الحساب في التسجيل).
- **شخصي:** الحقول الحالية (اسم عربي/إنجليزي، هاتف، جنسية، جنس، ميلاد؛ البطاقة والجواز اختيارية).
- **تجاري (مستأجر):** يلزم:
  - اسم الشركة عربي/إنجليزي
  - اسم المفوض عربي/إنجليزي
  - رقم السجل التجاري
  - هاتف
  - مرفق **السجل التجاري** (`commercial_register`)
  - مرفق **تفويض المفوض** (`authorization_letter`)
- الحفظ عبر `PATCH /api/account` يرفض التجاري بدون المرفقين (`COMPANY_FILES_REQUIRED`).
- الرفع عبر `POST /api/account/file` بنفس قيود الصورة/PDF حتى 4 ميغابايت.

## ملفات

- `app/account/AccountConsole.tsx` — واجهة التوثيق والمرفقات
- `app/lib/auth/account-files.ts` — أنواع الملفات الجديدة
- `app/lib/auth/users.ts` — التحقق عند الحفظ + السماح بالتبديل شخصي↔تجاري
- `app/api/account/route.ts` — رسائل الخطأ
