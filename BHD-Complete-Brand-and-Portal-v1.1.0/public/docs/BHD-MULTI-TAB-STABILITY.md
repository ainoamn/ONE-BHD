# استقرار تعدد الحسابات / التبويبات

> **التاريخ:** 29 أكتوبر 2026  
> **المشكلة:** وميض الصفحات عند التنقل، وتبدّل الحساب لحظياً ثم عودته — خاصة مع تبويبين بحسابين.

## السبب

كوكي جلسة المنتج مشترك بين كل تبويبات نفس الموقع. كل تبويب كان يصلح الكوكي بصمت عبر `silentRebind` ثم يعمل `location.replace`، فيسرق الكوكي من التبويب الآخر → حلقة إعادة ربط ووميض.

## الإصلاح

1. **ممنوع** `location.replace` بعد إصلاح JSON صامت — الكوكي يُحدَّث مكانه فقط.
2. **التبويب المركّز الظاهر فقط** يحق له كتابة كوكي المنتج (`tabMayClaimProductCookie`).
3. بعد إصلاح فعلي: حدث `bhd:account-rebound` → `router.refresh()` ناعم (بدون إعادة تحميل كاملة).
4. تهدئة أطول (45–60 ثانية) بين محاولات الإصلاح لنفس الحساب.
5. الإبقاء على `?au=` في الرابط عبر `history.replaceState` دون تنقل.

## التبديل الصريح

تبديل الحساب من القائمة ما زال يستخدم الغطاء الفارغ + مسار hard rebind — هذا مقصود.
