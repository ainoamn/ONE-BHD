# BHD Portal

البوابة الرسمية لمنظومة **Bin Hamood Development**. تعرض الشركة ومنتجاتها
الرقمية، وتشرح بنية المنظومة وخطة الحساب الموحد دون دمج البيانات التشغيلية
للتطبيقات داخل البوابة.

الشعار داخل الموقع أعيد بناؤه بصيغة SVG متجهية مع نسخ PNG عالية الدقة،
وأصوله موجودة في `public/brand`.

المرجع الكامل للبنية والأمان والأداء وSEO وربط المنتجات والدخول الموحد
والتحكم المركزي موجود في:

[`docs/BHD-PORTAL-DOCUMENTATION.md`](docs/BHD-PORTAL-DOCUMENTATION.md)

## الصفحات

- `/` الصفحة الرئيسية
- `/products` دليل المنتجات
- `/products/[slug]` صفحة كل منتج
- `/about` الشركة والرؤية
- `/technology` البنية التقنية
- `/security` الأمان والثقة
- `/privacy` الخصوصية
- `/terms` الشروط
- `/contact` التواصل
- `/apps` مشغّل التطبيقات
- `/login` صفحة تعريفية للحساب الموحد حتى إطلاق BHD Identity

## مبادئ البنية

- البوابة لا تخزن بيانات WAZEN أو HISAB أو NASAB أو بقية المنتجات.
- كل منتج يملك مستودعه ونشره وقاعدة بياناته وصلاحياته المحلية.
- تسجيل الدخول الموحد المستقبلي يعتمد OpenID Connect وOAuth 2.0.
- الروابط الخارجية معزولة، ولا توجد نماذج تجمع بيانات شخصية في النسخة الحالية.

## الحماية الحالية

- HTTPS/TLS في النشر.
- Content Security Policy.
- HSTS ورفض التضمين داخل الإطارات.
- تقييد صلاحيات المتصفح غير المطلوبة.
- منع فهرسة وتخزين صفحة الدخول المستقبلية.
- تعطيل إمكانات المتصفح غير المطلوبة ومنع التضمين والـcross-domain policies القديمة.
- اختبارات آلية للصفحات الأساسية ورؤوس الحماية.

## التشغيل والفحص

يتطلب Node.js `>=22.13.0`.

```bash
npm install
npm run dev
npm test
```

النشر على Vercel يجب أن يستخدم مجلد التطبيق:

`BHD-Portal-GitHub-Source-v1.0.0`

في إعدادات المشروع: **Root Directory** = `BHD-Portal-GitHub-Source-v1.0.0`، والإطار **Next.js**.

`npm test` يبني نسخة الإنتاج، يختبر المسارات الأساسية، ويتحقق من سياسات الأمان.

لإعادة إنتاج أصول العلامة والصورة المحسنة:

```bash
python scripts/render_brand_assets.py
python scripts/optimize_site_images.py
```
